# Guides

<p align="center"><img src="../images/ori/planning.svg" width="120" alt="Ori holding a checklist"></p>

Step-by-step walkthroughs for the most common setups. Each takes about
fifteen minutes and assumes Conduit is installed ([install.md](../install.md))
and you've created the owner account.

- [Developers](developers.md): servers, containers, CI and errors in one
  place, with an agent that fixes things only after you approve the diff.
- [Gamers](gamers.md): game mode, your game servers, stream controls and
  your PC's health on your phone.
- [Homelabs](homelab.md): Proxmox or TrueNAS, DNS blocking, backups and an
  ambient status light.
- [Teams](teams.md): people and roles, single sign-on, shared rules for
  agents, an audit trail and on-call.
