# Object storage (S3)

Buckets and files in any S3-compatible storage: MinIO, Garage, Cloudflare R2,
Backblaze B2, Wasabi or AWS S3.

**Setup.** Create an access key on the storage (MinIO: Access Keys; R2:
Manage R2 API Tokens; B2: Application Keys), store the secret half in the
vault, and enter:

| Setting | Example |
| --- | --- |
| `endpoint` | `https://minio.home.lan:9000`, `https://<account>.r2.cloudflarestorage.com`, `https://s3.eu-central-1.amazonaws.com` |
| `region` | `us-east-1` (default), `auto` for R2, the bucket's region for AWS |
| `accessKeyId` | the public half of the key |
| `secretKey` | `secret://…` |
| `virtualHost` | on for AWS-style `bucket.host` addresses; off (path style) for MinIO and Garage |

Plain `http://` is only accepted for `localhost`.

| Action | Risk | Notes |
| --- | --- | --- |
| `buckets` | read | |
| `objects` | read | Under an optional `prefix`, at most 1,000 per call; `more` says whether there are others. |
| `info` | read | Size, content type, last change, ETag and storage class (a HEAD request). |
| `usage` | read | Counts and adds up sizes, page by page; stops after 50,000 objects and says `complete: false`. |
| `link` | read, sensitive | A presigned download link valid for 1 to 168 hours (S3's 7-day limit). Anyone with the link can download the file, so the output is treated as sensitive. |
| `delete` | destructive | The preview shows the object's size and type. Without bucket versioning the file is gone for good, so there is no undo. |

Requests are signed with AWS Signature Version 4 (the same signer as the
[AWS module](aws.md)). Bucket names must follow S3's rules and keys can't
contain control characters or `.`/`..` segments, so nothing reaches a
different path than the one you asked for.
