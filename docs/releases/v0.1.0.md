# Conduit v0.1.0

Released 2026-11-03.

The first release. Conduit is one control plane for what you run (mail,
secrets, servers, containers, dashboards, local processes, games, your home)
where AI agents work under rules you set.

## In this release

- **The daemon** (`conduitd`) with 20 built-in modules: vault, this
  computer, servers over SSH, Docker, mail, calendar, notifications,
  Prometheus and Grafana, uptime checks, GitHub, GitLab, Cloudflare, Home
  Assistant, Discord, files and backups, games (Steam), notes, automations,
  the daily brief and ambient status.
- **Your own modules** in any language over JSON-RPC (kits for Go, Python and
  TypeScript), any MCP server mounted as a module, and untrusted modules in a
  WebAssembly sandbox with granted hosts only.
- **Agents under rules**: the built-in assistant (local models, API keys or a
  custom endpoint), any MCP client, agent keys. Policies per agent, system
  and action; approvals that show the exact change; a tamper-evident audit
  log; undo; an emergency stop.
- **Apps**: desktop (Windows, macOS, Linux) with a tray and signed updates;
  Android, pairing by QR code and confirming approvals with your fingerprint.
- **The hub** (`conduit-hub`): accounts, organisations, device pairing, an
  end-to-end encrypted relay, sync, the module registry and update feeds.
  Self-host it with SQLite or PostgreSQL; mail through Resend or SMTP, set by
  whoever runs the hub.
- **The website** in `site/`, served by any hub: downloads, docs and account
  pages.
- **The developer API**: OpenAPI 3.1 specs for both APIs, API keys with
  scopes, expiry, IP limits, rate limits and usage logs, and generated
  TypeScript and Python clients.

## Security

Before release, an independent review covered the vault, keys, auth, relay,
updater, sandbox and hub. Every issue it found is fixed in this release; see
BUILD_LOG.md, phase 15.

## Install

- **Desktop**: the installer for your system below.
- **Android**: `conduit-android-0.1.0.apk` below. Allow installs from your
  browser or file manager when asked.
- **Daemon only**: `conduitd-<os>-<arch>`; run it and open
  http://127.0.0.1:7600. Check downloads against `SHA256SUMS`.
- **Hub**: see docs/self-hosting.

## Known limits

- The Android app has been built and checked in CI but not yet tried on many
  devices.
- Releases are signed only when the signing keys are set up as repository
  secrets; until then the desktop and daemon don't treat a release as an
  update, and the APK is unsigned.
