# Conduit v0.3.0

Released 2026-11-04.

Twenty-six more modules, the app in German, encrypted backups, two-factor
sign-in, a command-line tool, modules from your hub, restricted vault
folders for teams, and container images.

## New

- **Twenty-six modules** (53 in all). For homelabs: TrueNAS, Pi-hole,
  AdGuard Home, UniFi, Nextcloud, Jellyfin, Plex, Vaultwarden, Uptime Kuma,
  Tailscale, S3-compatible storage (MinIO, R2, Garage). For developers:
  Hetzner Cloud, DigitalOcean, Vercel, Fly.io, PostgreSQL and MySQL, Redis
  and Valkey, Gitea and Forgejo, container registries, Linear, Sentry,
  PagerDuty, Ollama. For gamers and streamers: Minecraft and Source game
  servers, Twitch, Mastodon. Notifications also go to Matrix, Gotify and
  email.
- **Deutsch.** The whole app is available in German; it follows your
  browser until you pick a language in Settings, Appearance.
- **Encrypted backups.** One file with everything, encrypted with a
  passphrase; download it, or write one every day to another disk. Restore
  with `conduitd restore`.
- **Two-factor sign-in** with any authenticator app, and recovery codes.
- **The `conduit` command.** Run actions, list instances, approve requests
  and follow the timeline from a terminal or a script.
- **Modules from your hub.** Browse your hub's registry and install signed,
  sandboxed modules; the author's key is pinned on first install.
- **Restricted vault folders.** The owner can limit folders such as
  `finance/` to certain roles and people, admins included.
- **Home tiles.** Put the numbers you check most on the home screen.
- **Find daemons on your network** (mDNS) when pairing.
- **Hub operator console** for the people who run a hub.
- **Container images** for the daemon and hub (multi-arch, on GHCR), a
  Compose file and a Helm chart for the hub.
- **Guides** for developers, gamers, homelabs and teams.

## Security

Two independent reviews covered this release (BUILD_LOG.md, phases 30
and 33). Every confirmed finding is fixed here; the main ones were in
restricted vault folders (escaped references, imports, scans and sync),
read-level database queries, game server chat commands, mDNS amplification
and author handles on the hub. Browser tests and an accessibility scan now
run in CI.

## Upgrade

Replace the binary, or let installed daemons update themselves once
releases are signed. Database changes run on start. Backups need
v0.3.0 or later to restore. The relay protocol is unchanged.
