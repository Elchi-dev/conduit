# Conduit v0.3.1

Released 2026-11-04.

The first signed release. Nothing new to use, but everything you download
is now signed:

- **Android:** the APK is signed, so it installs and updates in place, and
  the F-Droid repository is published with it.
- **Desktop:** the apps update themselves when a new version is out.
- **Daemon:** installers and self-updates check each download against the
  release signature.

Conduit is now MIT licensed.

## Upgrade

Install this one by hand once (earlier builds were unsigned); from here on,
updates arrive on their own.
