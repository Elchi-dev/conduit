# SDKs

- [`external/`](external/): starter kits for writing modules in Python,
  TypeScript and Go (JSON-RPC over stdio, or WebAssembly for Go).
- [`clients/`](clients/): API clients. `clients/typescript` is a typed client
  for the daemon and hub generated from the OpenAPI specs;
  `clients/python` is a one-file standard-library client for scripts.

For AI agents, use MCP instead of a client: see `docs/api/mcp.md`.
